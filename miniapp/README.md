# Навигатор мер поддержки — mini app для MAX

Адаптивный React-интерфейс по макету Figma: рекомендации, каталог, карточка программы, «Мои программы», чек-лист, профиль и карточка документа.

## Локальный запуск

```bash
npm ci
npm run dev
```

Сборка: `npm run build`. Готовые файлы будут в `dist/`. Локально можно проверить интерфейс и логику; работу внутри MAX проверяют после размещения приложения на публичном HTTPS-адресе и подключения к боту.

## Запуск в Docker

```bash
docker build -t max-support-miniapp .
docker run --rm -p 8080:80 max-support-miniapp
```

После запуска демо доступно по адресу `http://localhost:8080`. Для MAX нужен публичный HTTPS-адрес; сам контейнер отдаёт статические файлы по HTTP и может работать за HTTPS-прокси.

## Что работает в демо

- 19 программ загружаются из `src/data/support_programs.json` (снимок от 22.09.2026). Данные **тестовые**; перед реальной подачей нужно проверить условия, сроки и ссылки у организатора.
- Предварительный подбор учитывает регион, сферу и приоритет. Он не проверяет возраст, доход, статус МСП, долги и другие условия участия. Это не решение о праве на поддержку.
- Поиск, фильтры, сохранение и отметки документов работают локально. Состояние хранится в `localStorage` текущего браузера. Первые три программы и отметки документов заполнены как демонстрационный пример макета.
- В MAX подключается официальный `max-web-app.js`. Имя из `initDataUnsafe.user` используется **только для отображения**. Для авторизации и API сервер обязан проверять исходную строку `WebApp.initData`; `initDataUnsafe` нельзя считать проверенным идентификатором.
- Ссылка на источник открывается через `WebApp.openLink` внутри MAX и через обычный браузер вне MAX.
