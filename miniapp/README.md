# Навигатор мер поддержки — mini app для MAX

Адаптивный React-интерфейс: рекомендации, каталог, карточка программы, «Мои программы», чек-лист документов, профиль и карточка документа с картой пунктов выдачи.

## Данные

Приложение **не хранит собственного каталога и не повторяет логику подбора** — всё приходит с backend:

| Что | Откуда |
|---|---|
| Каталог программ | `GET /api/v1/programs/` |
| Рекомендации и причины подбора | `GET /api/v1/programs/match/me?limit=50` |
| Варианты в выпадающих списках | `GET /api/v1/options/` |
| Профиль | `GET /api/v1/profile/me`, `POST /api/v1/profile/` |
| Сохранённые программы и отметки документов | `/api/v1/applications/` |

В `localStorage` остаётся только то, что и должно быть локальным: отображаемое имя и переключатели уведомлений.

## Локальный запуск

```bash
npm ci
npm run dev
```

Dev-сервер проксирует `/api` на `http://localhost:8000` — адрес меняется переменной `VITE_DEV_API`. Backend нужно поднять с `REQUIRE_SIGNED_INIT_DATA=False`, иначе вне MAX подписи `initData` не будет и API ответит 401.

Тесты: `npm test`. Сборка: `npm run build` → `dist/`.

## Запуск в Docker

Проще всего через общий стек из корня репозитория (`docker compose up --build`) — тогда nginx сам проксирует `/api` на backend и приложение обращается к своему же origin: ни CORS, ни mixed content настраивать не нужно.

Отдельно:

```bash
docker build -t max-support-miniapp .
docker run --rm -p 8080:80 max-support-miniapp
```

Для MAX нужен публичный HTTPS-адрес; контейнер отдаёт HTTP и рассчитан на работу за HTTPS-прокси. Если backend живёт на другом домене, задайте адрес при сборке: `--build-arg VITE_API_BASE_URL=https://api.example.ru`.

## Авторизация

Внутри MAX приложение отправляет сырую строку `WebApp.initData`, подпись которой проверяет сервер. `initDataUnsafe` используется **только** для показа имени и никогда как идентификатор. Вне MAX (локальная разработка) клиент подставляет стабильный для браузера `X-Max-User-Id` — такой запрос продовый backend отклонит.

## Что важно знать о демо

- 19 программ — тестовый снапшот от 22.09.2026. Перед подачей проверьте условия, сроки и ссылки у организатора.
- Подбор учитывает статус, регион, сферу и приоритет. Он не проверяет возраст, доход, наличие в реестре МСП, задолженности и прочие условия участия. Это не решение о праве на поддержку.
- Ссылка на источник открывается через `WebApp.openLink` внутри MAX и в новой вкладке вне его; открываются только `https`-ссылки.
- В карточке документа показаны пояснение, порядок подготовки и карта пунктов МФЦ или ФНС, если документ получают через госуслугу. Поиск использует Photon и OpenStreetMap; по умолчанию точки ищутся от центра региона из профиля, кнопка «Моё местоположение» запрашивает разрешение браузера. Карта и Leaflet подгружаются только при открытии этой страницы.
- Переключатели уведомлений пока ничего не рассылают.
